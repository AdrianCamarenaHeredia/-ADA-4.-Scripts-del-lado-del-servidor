Bienvenido a mi proyecto

Este sitio web ha sido creado para mostrar la evolución de la web a lo largo de los años. Es un proyecto académico que demuestra el uso de HTML, CSS y JS.

Características del sitio:

  • Navegación interactiva con CSS.
  • Formulario validado con JavaScript.
  • Uso de tablas estructuradas.

Pasos para la web moderna:

  1. Consolidación de estándares (W3C).
  2. Surgimiento de la Web 2.0.
  3. Masificación de los dispositivos móviles.
